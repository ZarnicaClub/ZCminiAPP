# Реестр текущего состояния веб-части CRM

> **Zarnica CRM Mini App** (Telegram Mini App)
> Версия: **v12.10** · Дата фиксации: **28.08.2026**
> Файлы фронтенда: `crm/templates/index.html`, `crm/static/app.js`, `crm/static/style.css` (встроены в `crm/webassets.py`, генерируются `scripts/gen_webassets.py`).

---

## 1. Обзор

Одностраничное приложение (Vanilla JS, без фреймворков):

- 5 экранов + нижняя навигация + модальный диалог.
- Стартовый экран — 4 квадратные кнопки; на внутренних экранах появляется фиксированная нижняя навигация.
- Данные загружаются через API (без изменений БД/бэкенда):
  - `GET /api/orders`
  - `GET /api/clients`
  - `GET /api/orders/{order_id}/calls`
  - `GET /api/clients/{client_id}/calls`
  - `GET /api/calls/today`
  - `GET /api/summary/weekend`

## 2. Сущности (данные)

### 2.1 Заказ — `Order`
| Поле | Источник/примечание |
|---|---|
| `order_id` | № заказа |
| `status` | `order_status` (напр. `paid`) |
| `payment.amount / currency / system / transaction_id` | оплата |
| `customer.name / email / phone` | клиент |
| `event.date / game / tent / session / qty` | дата, игра, размещение, сеанс, кол-во |
| `received_at` | когда поступил |

> `event.session` — период сеанса из Tilda (напр. `- Утренний с 9:00 до 14:45;`), не конкретное время.

### 2.2 Клиент — `Client`
| Поле | Примечание |
|---|---|
| `client_id` | ID |
| `name / phone / email` | данные |
| `orders_count / calls_count` | счётчики |
| `last_call_at` | последний звонок |

### 2.3 Звонок — `Call`
| Поле | Примечание |
|---|---|
| `call_datetime` | дата/время |
| `administrator` | администратор |
| `phone` | телефон |
| `duration_seconds` | длительность |
| `audio_url` | presigned MP3 (S3) |

## 3. Экраны

| Экран | `id` | Содержимое |
|---|---|---|
| Стартовый | `screen-start` | заголовок CRM + 4 кнопки (Расписание / Клиенты / Заказы / Звонки) |
| Расписание | `screen-schedule` | месяц, неделя, панель дня, Утро/Вечер, список записей + бейдж «Ожидаем в выходные» |
| Клиенты | `screen-clients` | список клиентов |
| Заказы | `screen-orders` | чипы фильтров + список заказов |
| Звонки | `screen-calls` | звонки за сегодня |

Нижняя навигация `bottomNav` (4 пункта: Расписание / Клиенты / Заказы / Звонки), скрыта на стартовом экране.

## 5. Метки (текстовые элементы)

### 5.1 Общие / шапки
| Где | Текст |
|---|---|
| Бренд в шапках | ЗАРНИЦАКЛАБ |
| Заголовки экранов | Расписание / Клиенты / Заказы / Звонки |
| Стартовый экран | CRM · mini app |
| Бейдж «Ожидаем в выходные» | 👥 + число (`#weekendCount`) |
| Месяц | «Август 2026» + стрелки ‹ › |
| CTA | «＋ Новая запись» (неактивна) |
| Фильтр | ☷ (неактивен) |
| Дни недели | Вс Пн Вт Ср Чт Пт Сб |
| Точка дня с записями | ● |
| Панель дня | «Сб, 25 июля» + «Сводка дня появится здесь» |
| Переключатель Утро/Вечер | ☀ Утро 09:00–14:45 / ☾ Вечер 15:15–21:00 |
| Чипы заказов | Все / Ближайшие / Оплачено |

### 5.2 Карточка расписания
- период: **Утро / Вечер / Сеанс** (из `sessionInfo()`)
- игра (или «Игра не указана»)
- цена «N ₽»
- «N чел.»
- имя (или «Без имени»)
- 📞 (tel-ссылка)
- строка «09:00–14:45 · paid»

### 5.3 Карточка заказа
- 📅 дата (или «Дата не указана»)
- статус (или «—»), для `paid` дополнительно «N RUB»
- имя (или «Без имени»)
- 👥 N (игроков)
- 🕒 сеанс (или «Сеанс не указан»)
- 🎯 игра
- 🏕 размещение
- «Поступило: …»

### 5.4 Карточка клиента
- имя (или «Без имени»)
- «📞 … · заказов: N · звонков: N»
- «🕒 Последний звонок: …»

### 5.5 Карточка звонка
- 📞 дата/время (или «Дата не указана»)
- длительность mm:ss
- администратор (или «Администратор не указан»)
- телефон
- аудио (или «MP3 недоступен»)

### 5.6 Диалог заказа
- заголовок: имя (или «Заказ»)
- бейдж статуса
- grid-поля: Заказ / Дата / Сеанс / Игроков / Игра / Размещение / Оплата / Транзакция
- действия: 📞 tel, ✉️ email (копия)
- «Звонки» + «Загрузка звонков… / Звонков пока нет / Не удалось загрузить звонки: …»

### 5.7 Диалог клиента
- имя + «#client_id»
- подпись «Карточка клиента»
- действия: 📞 (копия), ✉️ (копия)
- «Заказы (N)» — мини-карточки (#id + дата) или «Заказов нет»
- «Звонки» или «Звонков нет»

## 8. Замечания / точки для корректировки

- Конкретное время сеанса в данных отсутствует — период «Утро/Вечер» выводится из `session_time`.
- Кнопки «＋ Новая запись» и фильтр «☷» — визуальные заглушки (функционал не реализован).
- Переключатель «Утро/Вечер» — визуальный, без фильтрации списка.
- Панель «Сводка дня» — заглушка под будущее наполнение.
