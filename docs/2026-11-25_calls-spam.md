# Спам-звонки: скрыть из CRM, оставить в базе (13.24, 25.11.2026)

Задача Артёма: в разделе «Звонки» убрать спам-звонок из отображения CRM.
**Из базы не удаляем** — ставим пометку, запись остаётся.

## Решения (25.11.2026)

- **1В** — звонок, привязанный к заказу (`order_id` заполнен), скрывать нельзя вообще.
- **2А** — помечать может только редактор из `crm_editors` (`require_editor`).
- **3Б** — только по одному, массовой кнопки нет.

## Как хранится

В существующем `calls.metadata`, без миграции и новых таблиц:

```json
"spam": {"at": "2026-11-25T10:00:00+00:00", "by": 828432096, "name": "Артём Коробов"}
```

`calls_tagger` пишет metadata через `||`, поэтому метку не затирает.
Вернуть звонок — удалить ключ: `metadata - 'spam'`.

## API

- `POST /api/calls/{id}/spam` `{"hidden": true|false}` — только редактор.
  404 `call_not_found`, 409 `call_linked_to_order` (1В), 403 `editing_forbidden` (2А).
- `GET /api/calls/today?date=ГГГГ-ММ-ДД&include_spam=1` — скрытые отдаёт только редактору;
  в ответе всегда `spam_count` за день (для переключателя «Показать скрытые (N)»).
- `GET /api/calls/unmatched?include_spam=1` — то же правило.

По умолчанию списки звонков скрытые не отдают: `AND (%s OR NOT (metadata ? 'spam'))`.

## Интерфейс

- В карточке звонка без заказа у редактора появляется «⋯» → шторка «Скрыть звонок как спам?».
- После скрытия — тост «Скрыт как спам · Вернуть» (10 секунд) и перезагрузка списка.
- Переключатель «Показать скрытые (N)» под сводкой: скрытые карточки показываются серыми,
  у каждой кнопка «Вернуть в CRM».
- У привязанного к заказу звонка кнопки нет — правило 1В на клиенте и на сервере.

## Проверка

`pytest -q tests/test_calls_spam.py` — права, 409 для привязанного, снятие метки, выдача скрытых.
Локальный стенд: скрыть/вернуть звонок без заказа, убедиться, что счётчик «Звонков за день» уменьшился,
а строка в базе осталась (`select metadata->'spam' from calls where id = …`).
