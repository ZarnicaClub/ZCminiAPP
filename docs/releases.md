**Состояние на 25.10.2026.** Этот файл — единая справка по версиям: что вошло, когда и где
смотреть подробности. Технические детали — в `docs/`, читательский разбор каждого выката —
в волте Obsidian (`Проекты/ЗарницаКлаб/`).

## Где живёт версия

- **`VERSION`** в корне репозитория — единственный источник правды. Это же число носит тег образа
  в Docker Hub (`amkorobov/zc-web:<версия>`) и тег приложения в Timeweb App Platform.
- **`APP_VERSION`** в `app/main.py` держим равной `VERSION`: по строке лога `zc-app 13.14 запущен`
  сразу видно, что доехало.
- Новый релиз = правка `VERSION` + push в `main` → GitHub Actions прогоняет тесты, собирает образ
  и сам переключает приложение на новый тег. Порядок — `README.md`, раздел «Релизы».

  **11.10.2026 база переразмечена по правилам v3: 40 звонков, `source=rules-v3`.**

## Куда смотреть по коду

- Точка входа приложения — `app/main.py` (`APP_VERSION`).
- Мини-апп — `crm/` (шаблоны и статика) → встроенный фронт `crm/webassets.py`,
  пересобирается `scripts/gen_webassets.py` после правок `crm/templates|static/`.
- Воркер звонков — `calls_worker/`, разметка звонков — `calls_tagger/`, вебхуки Тильды — `orders_webhook/`.
- Схема БД — `migrations/` (Alembic), описание доступа — `docs/crm-service-snapshot.md`.
- История версий — `git log --date=format:'%d.%m.%Y' --pretty='%h %ad %s'`.
