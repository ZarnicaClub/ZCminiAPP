- **Дата:** 04.09.2026
- **Версия:** v12.17
- **Сервис:** `crm` (встроенный фронтенд `crm/webassets.py`)
- **Образ:** `amkorobov/crm:12.17`

---

## Цель

Исправить фильтр по дате в разделе «БСО» (введён в v12.16): полоса дат «прилипала» к крайнему левому чипу «Все» и не позволяла нормально листать даты назад/вперёд. Приведён к тому же поведению, что и раздел «Заказы».

## Что изменено

### `crm/templates/index.html`
- В экран `screen-bso` добавлена строка фильтров `#bsoFilterRow`: чипы **«Все»** (активна по умолчанию) и **«Выбор даты»**.
- Контейнер полосы дат `#bsoDateStrip` теперь скрыт по умолчанию (`hidden`).

### `crm/static/app.js`
- `state`: добавлен `bsoFilter` (`"all"` по умолчанию).
- `renderBsoDateStrip()`: полоса дат показывается только при `bsoFilter === "date"` (иначе `hidden`); рендерится без чипа «Все», по умолчанию активна «сегодня», листается в обе стороны (как в «Заказах»).
- `renderBso()`: фильтрация по `game_date` выполняется только при активном «Выбор даты» и выбранной дате; сводка показывает «БСО: N» либо «БСО за ДД.ММ.ГГГГ: N».
- Обработчики чипов разведены по скоупу: `#ordersFilterRow .chip` (заказы) и `#bsoFilterRow .chip` (БСО), чтобы переключение одного экрана не сбрасывало фильтр другого.

### `crm/webassets.py`
- Перегенерирован скриптом `scripts/gen_webassets.py` (55 077 → 55 879 байт).
