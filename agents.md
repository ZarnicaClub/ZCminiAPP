Алгоритм внесения изменений в любой из сервисов приложения crm / orders_webhook / calls_worker

1. Сделать бэкап текущей версии (кладем их в папку \newCRM\_архив_данных);
2. Вывести команды для cmd для деплоя через Docker HUB (всегда проверяй какая была последня версия, пиши следующую :v...., не пиши latest);
3. Дождаться от пользователя результат деплоя на сервер;
4. После подтверждения успешного Деплоя создать файл отчет о внесенных изменениях, указать путь отчета;
